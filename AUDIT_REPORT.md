# Итоговый отчёт аудита — Neon Circuit (WebGL Racing)

Дата: 2026-08-27
Проект: webgl-racing (мультиплеерная 3D-гоночная игра, WebGL/Three.js)
Охват: полная кодовая база (6 клиентских модулей ~1500 LOC, сервер ~470 LOC, 3 карты, 35 тестов)

---

## Executive Summary

Проект Neon Circuit — рабочий мультиплеерный 3D-гоночный прототип с ретро-эстетикой (synthwave/CRT-шейдер), системой лобби, лидербордом, миникартой и дрифт-механикой. В рамках аудита проведены 4 параллельных анализа:

**Что найдено:**
- **12 багов** (1 критический, 3 высоких, 5 средних, 3 низких) и **6 пунктов технического долга**
- **16 точек роста** в 4 категориях (геймплей, архитектура, UX, контент)
- Ранее обнаруженные критические уязвимости **C1 (path traversal) и C2 (WS error handlers) — ИСПРАВЛЕНЫ**

**Что уже сделано в ходе аудита:**
- ✅ Полная аудио-система: процедурная синтвейв-музыка, звук двигателя, дрифта, столкновений, финиша (Web Audio API, без внешних файлов)
- ✅ Система частиц: искры дрифта, выхлопной дым, искры при столкновениях со стенами
- ✅ Улучшенная графика: bloom в CRT-шейдере, звёздное небо (300 звёзд), солнечное кольцо, неоновые полосы на стенах
- ✅ 10 UI/UX улучшений: исправлены CSS-баги, добавлены keyboard navigation, адаптивная вёрстка, анимации переходов

**Критический нерешённый баг:**
- **B1**: Клиент-авторитарный подсчёт кругов — отправка 3× `lap_complete` мгновенно выигрывает гонку. Требует немедленного исправления.

**Итого по матрице импакт × сложность:**
- 🔴 Quick wins (высокий импакт, низкая сложность): 5 пунктов
- 🟡 Средний приоритет: 6 пунктов
- 🟢 Перспектива: 7 пунктов

## 1. Критические баги (требуют немедленного исправления)

### B1 — КРИТИЧЕСКИЙ: Клиент-авторитарный подсчёт кругов

| Параметр | Значение |
|----------|----------|
| Файлы | `server.js:430-438`, `network.js:66` |
| Импакт | Мгновенная победа через 3 WebSocket-сообщения |
| Сложность исправления | Низкая |
| Статус | ⛔ Не исправлен |

**Проблема:** Клиент отправляет `lap_complete` без доказательств прохождения. Сервер принимает безусловно. Тесты сами эксплуатируют это — Алиса проходит 3 круга за <200 мс.

**Отягчающий фактор:** JSON-карты определяют checkpoints (4–8 точек), но ни клиент, ни сервер их не используют. Нет защиты от срезания, обратного пересечения стартовой линии, фиктивных кругов.

**Рекомендация:** Сервер должен отслеживать `trackT` игрока (уже получает в `state_update`) и валидировать прохождение чекпоинтов перед зачётом круга. Минимально — rate limit (>5 сек между кругами).

---

### B2 — ВЫСОКИЙ: `index.old.html` раздаётся через static

| Параметр | Значение |
|----------|----------|
| Файлы | `index.old.html`, `server.js:31` |
| Импакт | Раскрытие устаревшего кода со всеми уязвимостями из первоначального ревью |
| Сложность исправления | Низкая |
| Статус | ⛔ Не исправлен |

**Проблема:** Старая версия (352 строки, сырой WebGL) доступна по прямому URL. Содержит проблемы M1–M4 и m1–m4 из REVIEW.md.

**Рекомендация:** Удалить файл или добавить в `.gitignore`.

---

### B3 — ВЫСОКИЙ: 2 из 3 карт без декораций

| Параметр | Значение |
|----------|----------|
| Файл | `track.js:226-291` |
| Импакт | Desert Drift и Cyber Highway выглядят пустыми |
| Сложность исправления | Низкая |
| Статус | ⛔ Не исправлен |

**Проблема:** `_props()` обрабатывает только `tree`, `building`, `neon_sign`, `light_pole`. Не поддерживаются: `cactus` (6 шт.), `rock` (6), `barrier` (3), `ramp` (3), `bridge` (3) — итого 21 объект на двух картах.

**Рекомендация:** Добавить ветки для каждого типа (простая box-геометрия).

---

### B4 — ВЫСОКИЙ: Конвертер карт теряет данные

| Параметр | Значение |
|----------|----------|
| Файл | `track.js:33-48` |
| Импакт | Все карты выглядят одинаково, checkpoints не работают |
| Сложность исправления | Средняя |
| Статус | ⛔ Не исправлен |

**Что теряется:**
- `checkpoints` — не передаются (связано с B1)
- `theme` (skyColor, groundColor, ambientColor, fogDensity) — не передаются
- `walls[].side`, `walls[].color` — используется только первый элемент
- `difficulty` — не передаётся

## 7. Что хорошо

- **Безопасность:** C1 (path traversal) и C2 (WS error handlers) из предыдущего ревью исправлены
- **Тесты:** 35/35 интеграционных тестов проходят, покрывают полный цикл игры
- **Валидация ввода:** `clamp()` + `Number()` на state_update предотвращают мусорные значения
- **XSS-защита:** `esc()` в ui.js экранирует `<` и `>` в именах
- **Обработка отключений:** корректный cleanup при disconnect, удаление пустых комнат
- **CRT-шейдер:** стилистически сильный ретро-эффект с новым bloom
- **Аудио:** полноценная процедурная аудио-система без внешних зависимостей
- **Частицы:** визуальная обратная связь для дрифта, столкновений, выхлопа
- **Архитектура:** чистое разделение на модули (game, car, track, network, ui, minimap, audio, particles)
